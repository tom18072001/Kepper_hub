Hết cảnh báo "kết nối không riêng tư"

Kepler Hub chạy trong mạng nội bộ của công ty, dùng chứng chỉ do máy chủ công ty cấp. Máy của bạn cần tin chứng chỉ gốc này một lần, sau đó trình duyệt và ứng dụng Kepler Hub không còn cảnh báo.

1. Tải chứng chỉ gốc

Windows

  1. Mở tệp kepler-hub-ca.crt vừa tải → Install Certificate…
  2. Chọn Current User → Next.
  3. Chọn Place all certificates in the following store → Browse → Trusted Root Certification Authorities → OK → Next → Finish.
  4. Bảng cảnh báo hiện ra → Yes.
  5. Tắt hẳn Chrome / Edge và ứng dụng Kepler Hub, rồi mở lại.

Hoặc mở PowerShell trong thư mục Downloads, chạy: certutil -user -addstore Root kepler-hub-ca.crt → Yes.

macOS

  1. Mở tệp vừa tải → Keychain Access thêm vào login.
  2. Bấm đúp chứng chỉ "Caddy Local Authority" → Trust → When using this certificate: Always Trust.
  3. Đóng cửa sổ, nhập mật khẩu máy, mở lại trình duyệt.

Điện thoại

iPhone: mở link tải bằng Safari → Cài đặt → Đã tải về hồ sơ → Cài đặt; rồi Cài đặt → Cài đặt chung → Giới thiệu → Cài đặt tin cậy chứng nhận → bật cho chứng chỉ này.
Android: Cài đặt → Bảo mật → Mã hoá và thông tin xác thực → Cài đặt chứng chỉ → Chứng chỉ CA → chọn tệp vừa tải.

2. Mở Kepler Hub

Máy tính công ty trong domain thường đã được cài sẵn — nếu vẫn báo lỗi, báo quản trị CNTT. Không bấm "Nâng cao → Tiếp tục" để bỏ qua cảnh báo.
